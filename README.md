## My process

### Built with

- HTML5 – for the content structure and semantic markup
- CSS3 – for styling, layout, and responsive design
- CSS Grid – to create the main layout structure
- Flexbox – to align and distribute items inside components
- Custom properties (CSS variables) – to manage colors, fonts, and spacing consistently
- Google Fonts (Red Hat Display) – for typography styling
- Mobile-first workflow – to build the layout starting from smaller screens and scale up

### What I learned

I learned that it’s more efficient to complete a rough layout first and then refine the details later. Grouping similar tasks together saves time and improves productivity. Previously, I finished the entire mobile view before starting the desktop view, which caused a lot of extra work when making changes. Now I understand that building the structure first and then adjusting for different screen sizes is a much better approach.

### Continued development

I would like to add an interactive flip effect to the card, showing additional details on the back side while keeping the front side more minimal. This would make the component more engaging and add a creative touch to the overall design.
